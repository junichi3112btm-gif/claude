# 資料の分級批評

## 目的
資料を**出荷判定**にかける。指摘を並べるのではなく、
「いま出せるか／何を直せば出せるか」を確定させる。

## 分級の定義（この3段階を厳守）

| 級 | 定義 | 判定への効き方 |
| :-: | :-- | :-- |
| **第1級** | **出した時点で信用を失う** | 未了の間は**対外提示不可** |
| **第2級** | 論理が通っていない | 出せるが、読み手に疑問を生む |
| **第3級** | 詰め | 直せば良くなる |

**第1級に入るもの：**
- 事実の誤り（実在する別会社を名指し、未締結を締結済と書く、未受領を受領済と書く）
- **宣言と本文の不一致**（改訂履歴に「是正した」とあるのに本文が未修正）
  ── これは単独で第1級。他の全記述の信頼を損なうため
- 同一文書内の二重帳簿（同じ出来事・同じ数値が節によって違う）
- 秘密保持・未出願に触れる開示（NDA稼働中の実名、未出願特許の構造情報）
- 資料の格を落とす記載

**第2級に入るもの：** 版の取り違え、定義が実態を超えている（「いずれも」の過大）、
性質の違う話が未整理で並列、留保が必要な箇所の無印。

**第3級に入るもの：** 課題期間外の構想の混入、検証不能な比較、条件付与の漏れ。

## 手順（毎回この順で実行）

1. **前提の確認**：`CLAUDE.md` と `meta/数値台帳.md` を読む。
   正本はどれか、禁止語は何か、🔴が付いた数値はどれかを把握してから読み始める。
2. **機械検証を先に回す**：`python3 tools/verify.py --doc <対象> --profile <profile> --recompute`
   目で読む前に、禁止語・保持必須語・数値の不一致を潰しておく。
3. **通読**：節ごとに、主張・根拠・数値の3点が揃っているかを見る。
4. **横断照合**：同じ事実・同じ数値が複数の節に出ていないか。出ていれば**全部が一致するか**を確認する。
   （表・本文・脚注・見出しの4箇所。**第1.3版の事故は表だけが取り残された**）
5. **他文書との照合**：マスター正本（事業計画書 第1.8版）と矛盾しないか。
   同じ数値が別文書（デッキ・登壇原稿）に出ていないか。
6. **分級**：上の定義で仕分ける。**第1級は3件以内に絞る**。多いときは分級が甘い。
7. **良い箇所を書く**：何を壊してはいけないかが伝わらない批評は使えない。3〜5点。
8. **修正順序表**：優先順位を付け、**どこまでが対外提示のブロッカーか**を明記する。

## 出力フォーマット（この型を厳守）

```
# [資料名]（[日付]・[分量]）批評

**対象：** [ファイル名]
**批評日：** [日付]
**結論：** [第1級のN件を直すまで対外提示は不可 / 送付可。第1級・第2級の指摘なし]

---

## 第1級：出した時点で信用を失う

### ① [見出し（何が問題か1行で）]

現状の記載：
> [原文を引用]

[何が誤りか。事実の誤りなら「記載／事実」の対照表を作る]

**加重要因：** [それを悪化させている事情。なければ書かない]

## 第2級：論理が通っていない
### ④ [見出し]
[以下同様]

## 第3級：詰め
### ⑧ [見出し]

---

## 良い箇所
- **[節番号]** [何が良いか。なぜ良いかまで書く]

## 修正順序
| 優先 | 内容 |
| :-: | :-- |
| **1** | [第1級から順に] |

[N]〜[M] が未了の間は対外提示不可。

## 版の関係
[複数版が並行している場合、どれが何を含み、統合はどの向きが正しいかを書く]
```

## ルール

1. **原文を引用してから指摘する。** 引用のない指摘は検証できない。
2. **数値の誤りは算定式と正値を書く。** 「表が古い」ではなく
   「value($/bbl) = C[ppm] × 0.158987/1000 × price[$/kg]。$74.27 で 7ppm は 0.083（表は 0.076）」。
3. **事実の誤りは「記載／事実」の対照表にする。** 何が違うかが1行で見える形にする。
4. **第1級は絞る。** 全部を第1級にすると出荷判定として機能しない。
5. **良い箇所を必ず書く。** 是正で壊してはいけないものを明示するため。
6. **修正順序に「ここまでがブロッカー」の線を引く。**
7. 複数版が並行しているときは、**統合の向き**を明示する
   （例：「v1.3 を土台とし、項目1・9を当方正本から移植するのが正しい向き」）。
8. 出力は日本語。
