# 対外版の生成と送付前検証

## 目的
内部正本から対外版を作る。**内容は変更せず、除去のみ**で作る。
そのうえで4層の検証をかけ、再現可能な形で記録を残す。

## 大原則

**除去のみ。書き換えない。** 対外版で本文の主張・数値・構成を変えると、
内部正本と対外版が別文書になり、以後どちらが正しいか分からなくなる。
変更が必要なら**内部正本を直してから**対外版を作り直す。

---

## 第1部：生成

### 手順

1. **正本の確認**：`CLAUDE.md` の正本表で、どれが正本かを確定する。
   Drive 側が新しい可能性があるときは、**先に確認する**。
   （2026/08/28、ローカルコピーを正本と誤認して是正が分岐した事故がある）
2. **外部への送信履歴を確認する**：その相手が旧版を受領しているか。
   **受領していなければ、旧版との差分情報は載せない** ── 疑問を答えるのではなく生む。
3. **除去する4類型を洗い出す**：

   | # | 除去対象 | 理由 |
   | :-: | :-- | :-- |
   | ① | 正本メタデータ（HTMLコメント） | 版数の遍歴、git/Drive の分岐記録、バックアップ名、Drive fileId を含む |
   | ② | 内部の版表記 → 対外の版表記 | 対外的には初版が第1.0版 |
   | ③ | 改訂履歴の内部エントリ | 「適用漏れ」等の是正経緯を含む |
   | ④ | 前版参照・旧数値 | 対外版に「前版」は存在しえない |

4. **除去の妥当性を確認する**：除去した情報のうち、
   **読み手が数値を検証するために必要なものが失われていないか**を確認する。
   失われていれば除去しない。（例：グロス単価を用いる根拠と費用の個別控除は
   直前の2文に残っているため、前版比較を消しても検証材料は失われない）
5. **生成手順を記録する**：下のフォーマットで、何を除去したかと**再生成が必要になる条件**を書く。

### 生成手順の記録フォーマット

```
# 対外版 [版] の生成手順（再現可能な形で記録）

**内部正本** `[ファイル名]`（版は[内部版]）
  ↓ 次の[N]変換のみ
**対外版** `[ファイル名]`（[対外版]）

本文の内容は一切変更していない。除去のみ。

| # | 変換 | 理由 |
| :-: | :-- | :-- |

## 除去の妥当性
[検証材料が失われていないことの説明]
[外部への送信履歴の確認結果]

## 検証
[下の第2部の結果]

## 再生成が必要になる条件
内部正本を[次版]以降へ改訂した場合、対外版は自動では追随しない。
改訂のたびに上記[N]変換を再適用すること。
```

## 第2部：送付前検証（4層）

**PDF を作ったら、PDF の実体に対して検証する。** .md で検証しても体裁は分からない。

### ① 内部専用の記述の漏れ ── 対外版で最も重要

```bash
python3 tools/verify.py --doc <対外版> --profile external --recompute
```

機械検証が通ってから目視に移る。**例外を認めた語は、なぜ正当かを記録に書く**
（例：§13 出典の「執行計画書 第1.5版」は別文書の版であり正当）。

### ② 是正項目の保持

直前の批評で挙がった是正項目が、対外版にすべて残っているかを1件ずつ確認する。
`verify_rules.yaml` の `required` に登録してあれば機械で確認できる。

### ③ 数値の再計算

**PDF の実体に対して**再計算する。`--recompute` が算式を評価し、
単位語込みの原文と突き合わせる。表は**全行**照合する（1行でも取り残すと二重帳簿になる）。

### ④ PDF固有の体裁とメタデータ

- ページ数、空ページの有無、末尾（署名）まで到達しているか
- 表がページ境界で割れていないか。ページ先頭が表の途中になっていないか
- **文書プロパティ**：title に版数が入っていないか、author／subject／keywords、
  creator／producer にパス情報の漏れがないか
- 埋め込みファイル・注釈・しおりの有無、暗号化の有無

### 完了判定

```bash
python3 tools/verify.py --all
```

**対外提示物が不合格0を返すまで「送付可」と書かない。**

### 検証記録のフォーマット

```
# 対外版 [版] PDF 送付前検証記録

**対象：** `[ファイル名]`（[N]ページ）
**検証日：** [日付]
**結論：** [送付可。第1級・第2級の指摘なし / 送付不可。理由]

## 検証した4層
### ① 内部専用の記述の漏れ
### ② 是正[N]項目の保持
### ③ 数値の再計算（PDF実体に対して）
### ④ PDF固有の体裁

## 送付を止めない範囲の所見（任意）
[出せるが改善余地がある点。改善案まで書く]

## 検証時の偽陰性・偽陽性（手順の記録）
[自分の検査式に起因する誤判定があれば必ず記録し、教訓を1行にする]
```

## ルール

1. **除去のみ。** 本文を書き換えたくなったら内部正本へ戻る。
2. **旧版を受領していない相手に、旧版との差分を見せない。**
3. **検証は PDF の実体に対して行う。**
4. **自分の検証の誤判定を必ず記録する。** 文書側が正しいのに検出した／しなかったものは、
   検査式の欠陥であり、次回に持ち越す資産になる。
5. **再生成条件を必ず書く。** 対外版は内部正本に自動追随しない。
6. 送付を止めない所見と、止める指摘を**混ぜない**。
