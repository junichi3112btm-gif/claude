# メモ → 1ページまとめ

## 目的
雑然としたメモを、毎回まったく同じ型の1ページ要約に変換する。
読み手が30秒で「何が決まったか・誰が・いつまでに動くか」を把握できる状態にする。

## いつ使うか（トリガー）
- 「メモを整理して」「1枚にまとめて」「議事録をきれいにして」「議事録おこして」と言われたとき
- 箇条書き・走り書き・音声書き起こしを渡され、要約や整形を求められたとき

## 入力
- 生のメモ（テキスト、箇条書き、走り書き、音声書き起こしなど形式は問わない）
- 情報が欠けていても止まらない。不明な項目は「不明」と明記する。

## 手順（毎回この順で実行）
1. **読み込み**: メモ全体を通読し、話題のかたまりを把握する。
2. **分類**: 各行を4つに仕分ける —（a）決定事項（b）タスク／次アクション（c）論点・未決（d）背景・その他。
3. **タスク抽出**: 動詞で始まる行・「〜する必要」「〜依頼」などをタスクとして拾い、担当と期限を推定または「不明」とする。
4. **重複排除**: 同じ内容をまとめ、冗長な言い回しを削る。
5. **整形**: 下の「出力フォーマット」に流し込む。原文の事実は変えない。推測部分には（推定）と付す。
6. **最終確認**: スマホ1〜2画面に収まるか、決定・担当・期限に抜けがないかを確認する。

## 出力フォーマット（この型を厳守）
```
# [タイトル] ── [日付]

## 一言サマリー
（3行以内。この会議／メモで何が起きたか）

## 決定事項
- （決まったことを1行ずつ。なければ「なし」）

## ネクストアクション
| # | やること | 担当 | 期限 |
|---|---------|------|------|
| 1 |         |      |      |

## 未決・論点
- （持ち越し・要確認事項。なければ「なし」）

## 背景メモ
- （後で参照する補足。1〜3行）
```

## ルール
1. 事実を創作しない。メモに無い情報は足さない。推測は必ず（推定）と明示する。
2. 分量は1ページ（スマホ1〜2スクロール）以内。溢れたら「背景メモ」から削る。
3. タスクは必ず「動詞で始まる1行」にする（例：「田中さんに見積り依頼」）。
4. 担当・期限が不明でも欄は空にせず「不明」と書く。
5. セクションの順番・見出しは毎回固定。中身が無いセクションも見出しは残し「なし」と書く。
6. 出力は日本語。原文が英語混じりでも見出しは日本語に統一する。
