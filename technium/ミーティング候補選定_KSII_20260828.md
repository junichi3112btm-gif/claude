# TECHNIUM ミーティング候補選定：関西イノベーションイニシアティブ（KSII）

作成日：2026年8月28日

関西イノベーションイニシアティブ（**KSII**：Kansai Innovation Initiative）は、関西圏の大学・企業・金融機関・VC・自治体・支援機関を横断してつなぎ、大学発技術の社会実装と、社会課題を解く「ゼブラ企業」の創出・成長を目指す産学共創ネットワークです。2020年9月に経済産業省の産学融合先導モデル拠点創出プログラム「J-NEXUS」に採択されて始動し、公益財団法人都市活力研究所が推進しています。[^meti-kansai]

| 項目 | 内容 |
|---|---|
| 名称 | 関西イノベーションイニシアティブ |
| 略称 | KSII |
| 英文名 | Kansai Innovation Initiative |
| 推進主体 | 公益財団法人 都市活力研究所 |
| 発足の契機 | 2020年9月、経済産業省「産学融合先導モデル拠点創出プログラム（J-NEXUS）」に採択 |
| 主な対象地域 | 関西圏の大学・産業界・自治体等を横断 |
| 目的 | 大学シーズの社会実装、大学発スタートアップの創出・成長、産学融合エコシステムの形成 |
| 参画基盤 | 関西の大学を核に、企業、経済団体、金融機関、VC、研究機関、行政・自治体、産業支援機関等が参画[^meti-kansai] |

KSIIは法人格を持つ投資会社や単独アクセラレーターというより、複数の主体を束ねる**共創ハブ**です。各大学に散在する研究シーズと、企業・自治体が抱える事業課題を結び、共同研究、PoC、事業化、資金調達、顧客開拓へ進むための接点をつくることが中核機能です。[^ksii-about]

## 重点テーマ

KSIIが重視するのは、技術の新規性だけではなく、地域・社会の課題を解決しながら持続的に成長する「ゼブラ企業」の創出です。ゼブラ企業とは、急成長のみを追うユニコーン型とは対照的に、収益性と社会的インパクトを両立させる事業体を指します。[^meti-kansai]

主な活動は次のように整理できます。

- **大学シーズの発掘・可視化**：関西の大学が保有する研究成果・技術シーズを、企業や投資家が接続可能な形に整理します。
- **産学マッチング**：研究者・大学発スタートアップと、大企業、中小企業、自治体、金融機関等をつなぎ、協業テーマを具体化します。
- **PoC・社会実装支援**：技術検証だけではなく、顧客課題、実証フィールド、導入条件、事業モデルを含むPoC設計を支援します。
- **橋渡し人材の育成**：研究・技術と事業の双方を理解し、産学協業を動かせる人材・ネットワークづくりを進めます。
- **情報発信とコミュニティ形成**：イベント、セミナー、スタートアップ紹介、知財・事業化関連の企画を通じ、関西内外の連携を促します。[^meti-kansai]

2024年時点では、関西の30大学等に加え、経済団体、金融機関、自治体など合計91機関が参画しているとされています。参画数は継続的に変わり得るため、最新の連携先や募集プログラムはKSIIの公式サイトで確認するのが確実です。[^b2i]

## 資源循環との接点

加藤さんのように、希少資源回収、ヨウ素、廃液・随伴水処理、分離精製材料を事業化する立場から見ると、KSIIの価値は研究設備そのものより、**関西の技術・実証・顧客・資金をつなぐ機能**にあります。

| 事業課題 | KSIIを通じた接点の仮説 | 求める相手 |
|---|---|---|
| 分離回収技術の高度化 | 大学の材料、膜、吸着、化学工学、環境工学の研究シーズ探索 | 研究者、産学連携本部、大学発スタートアップ |
| 実証サイトの獲得 | 排水・廃液を抱える製造業、化学、金属、食品、自治体関連施設との接続 | 事業会社、自治体、産業支援機関 |
| 回収物の用途開発 | 回収ヨウ素・塩類・金属等の品質規格と顧客要求のすり合わせ | 化学メーカー、商社、ユーザー企業、分析機関 |
| 事業化・資金調達 | 技術のPoCから商用初号機までの資金・顧客・協業設計 | 地銀、地域金融、VC、CVC、事業会社 |
| 環境価値の設計 | 資源循環、排水削減、CO₂削減、地域産業課題への寄与の見える化 | 自治体、支援機関、ESG・GX関連企業 |

特にKSIIの「社会課題の解決と持続的成長」というゼブラ企業の枠組みは、資源回収のように、短期的な売上だけでなく、水質改善、廃棄物削減、輸入依存低減、地域雇用、脱炭素といった複数の価値を持つディープテックと親和性があります。[^meti-kansai]

## 持ち込み方

KSIIへの接触では、「技術を紹介したい」よりも、関西で実現したい**共創プロジェクト**として提示する方が適しています。例えば、次のようなテーマ設定です。

> 「高塩分・ハロゲン含有廃液から、選択分離によりヨウ素等の有価物を回収し、残液処理負荷も低減する分散型資源循環システム。関西の化学・材料・水処理の研究者、実証企業、用途開発パートナーと、ベンチ評価から実証サイト構築までを進めたい。」

初回説明資料は、以下の7項目で十分です。

1. **解く課題**：誰のどの廃液・随伴水処理課題を解決するのか
2. **原水条件**：対象濃度、流量、pH、塩分、共存イオン、有機物、変動要因
3. **技術の核**：吸着、膜、溶媒抽出、温度応答性材料などの独自性と代替技術との差
4. **実証データ**：回収率、選択性、濃縮倍率、再生回数、エネルギー・薬剤使用量
5. **事業性**：処理コスト、回収物価値、顧客導入メリット、初号機の販売・運用モデル
6. **関西で求める連携先**：研究者、排水保有企業、化学メーカー、装置メーカー、自治体、投資家など
7. **次の90日で進めること**：サンプル提供、分析、ベンチ試験、現場視察、共同PoCの設計など

## 注意点

KSII自体が研究を請け負う機関、補助金の交付主体、あるいは直接投資を行うVCであるとは限りません。そのため、相談時には「何を紹介してほしいか」「どの実証段階の案件か」「自社で用意できるデータ・試料・費用・実証先候補は何か」を具体的にしておくことが重要です。

また、J-NEXUSの補助期間は2024年度末までを見据えて自走する産学融合拠点を目標にしていたため、現在の運営体制、参画制度、支援メニュー、イベント・個別相談の受付条件は都度確認する必要があります。KSIIの公式サイトには現在も新規参画機関や知財・経営戦略に関するイベント情報が掲載されています。[^ksii-pdf]
