## 第1級：出した時点で信用を失う

### ① §7 K&O欄が v1.2 と一字一句同じ（是正9項目の第1項が未適用）

現状の記載：
> 2026年8月27日に協議（先方からの打診）。K&Oエナジーグループ、K&Oヨウ素、日本ガス、千葉県、伴走支援のCICが同席。目標は有償ベンチ実証への条件付きLOI。三者間NDA締結済

4点すべて誤り。

| 記載 | 事実 |
| :-- | :-- |
| 三者間NDA締結済 | **未締結**。8/27に効力開始日を「締結日」へ変更し修正版の送付待ち |
| 日本ガス | **関東天然瓦斯開発**。日本瓦斯（株）は実在する別会社であり、協議に出ていない会社を出席者として名指ししている |
| 先方からの打診 | 2026年7月15日に千葉県 渡邉様がK&Oエナジーグループ 髙木様を紹介したことが起点 |
| 目標は条件付きLOI | 未達。本協議の成果は**実液サンプル2〜3Lの提供合意** |

**加重要因：** §0 の変更記録に「顧客開発の進捗（7.）の事実関係の是正」と明記されているが、本文は未修正。宣言と本文の不一致は、他の全記述の信頼を損なう。

**加重要因2：** §3.2・§4 では同じ8/27協議から「10 ppm前後」「18,000〜19,000 m³」を引用済み。同一会議の記述が資料内で二重帳簿になっている。

### ② §5.3 が表・見出し・脚注で三者三様（$68/kg 削除の波及漏れ）

表は $68/kg 系列のまま。本文・脚注は $74.27/kg。見出しは両者の混合。

| 濃度 | 表の記載（$68系列） | $74.27 での正値 |
| :-- | --: | --: |
| 7 ppm | 0.076 | **0.083** |
| 20 ppm | 0.216 | **0.236** |
| 33 ppm | 0.357 | **0.390** |
| 60 ppm | 0.649 | **0.708** |
| 100 ppm | 1.081 | **1.181** |

- 見出し「回収経済が反転するのは **51〜116 ppm**」← 116 は $68 でしか出ない
- 本文「$74.27/kg で **51〜106 ppm**」← 正しい
- 脚注「国内テール 7 ppm は **$0.083／bbl**（$74.27/kg 換算）」← 正しいが、直上の表の 0.076 と矛盾

算定式：value($/bbl) = C[ppm] × 0.158987/1000 × price[$/kg]
- $74.27：0.60 → 50.8 ppm、1.25 → 105.9 ppm
- $68：0.60 → 55.5 ppm、1.25 → 115.6 ppm

### ③ §9 TOEIC 905点・§10 カルボニル基が残存（是正9項目の第9項が未適用）

TOEIC は格の問題。カルボニル基は性質が異なる — 応用特許①は**2026年10月出願予定で未出願**であり、その回避設計の構造情報を複数の推進機関候補へ配る資料に記載している。EPO にグレースピリオドはない。

## 第2級：論理が通っていない

### ④ §6.3 の版の取り違え
> 前版（第1.1版）は…投資回収期間を 3.88年としていました

**3.88年は第1.2版の値。第1.1版は「2.7〜4.1年」。** 版履歴の注記で版を誤ると、内容の誤りより強く効く。

### ⑤ §11 に繰延理由が2行、未整理で並列
「測定手段が確定していない → 判定時期を10月以降へ繰り延べます」と「判定が保留帯に入る → 本判定は10月へ繰延可能な設計」。性質が違う（測れない／測った結果が灰色）が、読み手には繰延の話が2つあるとしか見えない。

### ⑥ §2.2 の「いずれも」が過大
> 本表の百分率は、いずれも上澄み側の紫外可視吸光度（351 nm）の低下から算出した捕捉率です

表にはヘキサン中 73.9%/91.4% を含む。ヘキサンは有機溶媒であり「上澄み」という測定基準が成立しない。具体値の提示は純水系（0.345→0.011）のみ。定義を明記する節で定義が実態を超えている。

### ⑦ §1 に D が無印
§4 には r=92.9% の仮置き注記があるが、§1 の「FY2030到達目標売上は2億3,942万円」は無印。推進機関が最初に読むのは §1。§4 に注記があるぶん §1 の無印が際立つ。

## 第3級：詰め

### ⑧ §5.6 の第3・4段階
第2段階（臭素）は良い — 同一実験で判定でき、§11 のテール縮小リスクへの対応にも接続。
第3段階（非金属元素一般 FY2032）・第4段階（金属元素 FY2034）は本課題期間外。§3.5 の「参入障壁は強くないので濃度帯と運転データに絞る」と衝突する。第4段階は自ら「先行特許が存在するため権利範囲の再評価を要する」と記載しており、未評価領域を段階として並べている。
臭素について「かん水中の濃度がヨウ素を上回るため回収経済を改善しうる」— 濃度倍率が未記載で検証不能。

### ⑨ §12.2 の「事業計画書 第1.8版（本文）」提供が無条件
第1.8版には宿題16項目（西村准教授個人とのNDA不存在、応用特許①の m＝0 未収載、売上原価の根拠不明、r の根拠撤回の経緯）が含まれる。渡す版を分ける前提が必要。

### ⑩ §5.5 の 92.9% に〈仮置き〉表記なし
§4 のみ注記があり、節によって同じ数字の扱いが異なる。
