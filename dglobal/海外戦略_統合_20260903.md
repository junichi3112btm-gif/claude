## 5. なぜ「海外に売りに行かない」ことが収益上正しいのか

外部で生成される文書は、**3 回続けて同型の第1級**（第3弾 北米・第4弾 M&A・第8弾 インド）を出してきた。いずれも第3層を「顧客の増分売上または増分粗利に連動する報酬」の型に書き換えている。当社の確定モデルは異なる。

> **第3層＝回収量連動プロセス利用料（2,000 円/kg-I₂・従量課金・2026/09/01 加藤決定）。連動先は回収量（kg-I₂）であって、売上でも粗利でもない。**

この 1 行から、海外戦略の骨格が自動的に決まる。

| 論点 | 帰結 |
| :-- | :-- |
| 顧客が回収ヨウ素をどこへ売るか | **当社の収益は 1 円も変わらない。**国内でもインドでも同じ |
| したがって当社が販売先を開拓する動機 | **当社側には存在しない。**動機があるのは顧客 |
| 当社が顧客の販売先（商社・加工メーカー）へ直接接触したら | **Gate 1・Gate 3 の信頼を壊す。**実証相手の既存販売チャネル・価格交渉に踏み込む行為になる。M&A 規律の「顧客候補を売却・販売の駒として扱わない」と同じ構造 |
| 海外市場データの正しい使い道 | **顧客に示す材料。**当社の顧客 P/L は増産売上 5,085.1 万円（グロス 11,782 円 × 4,316 kg）を前提に置くが、これが成り立つのは顧客が増産分を売れる場合のみ。輸入需要の構造は「増産分に出口がある」ことの傍証になる〔要確認〕 |
| 当社が海外で行うこと | **回収の型を置くこと**（Phase 2 の北米）だけ。回収ヨウ素の所有・精製・販売・市況リスクは顧客 |

**書き方の規律：** 顧客に示すときも「当社が海外へ売る」とは言わない。「**増産分は貴社の既存の販売チャネルに乗る**」に留める。

## 6. 伊勢化学の二重性 ── 海外戦略で最も注意を要する 1 点

**同じ会社が、国内では実証パートナー（三者間 NDA 稼働中・9/1 白里工場見学）であり、北米では主回収の先行者である。**

| 事実 | 出所 | 確度 |
| :-- | :-- | :-- |
| Select Water Solutions と ISE Chemicals が 2026/6/25 に definitive agreement を公表。TX・NM・OK の Select 水インフラの produced water を原料に、米国子会社 Woodward Iodine Corporation を通じて抽出・精製施設を建設・所有・運転。**2030 年までに年約 3,000 t** を目標 | Select IR・PR Newswire ほか複数報道 | ⚠️ **二次経由・一次原文は本環境から取得不可。判断待ち #18 で再依頼中** |

- **競合として書けば国内関係を損ね、無視すれば北米戦略が実態と乖離する。** 一体で書く：「国内実証パートナーであり、北米主回収の先行者」。
- 当社の型（主回収の下流・低濃度水流の後付け）からは、**最も近い北米の接続点**でもある。濃縮物の引取先候補になりうる。
- **ただし北米を話題にするのは Gate 3 契約の後。** それまでに国内 Gate 3 の契約設計へ次の 3 点を先に織り込む：
  1. 三者間 NDA の**地理的範囲**に北米が含まれるか（判断待ち #14）
  2. 国内実証データが北米側の設計に流用されうるか（知財・データ利用範囲）
  3. 同社が自社でテール回収を内製する可能性
- **公開資料では実名を出さない**（CLAUDE.md §5.1）。北米の文脈でも同じ。「国内主要生産者 A社の北米案件（報道による）」まで。
