### 判定

- **今回（9/8 締切）：制度上は応募可能性があるが、推奨しない。** 理由：①株主要件・マッチング要件の設計に J-KISS 協議の具体化が必要（現在事前協議段階）②TRL4 実測前で技術根拠が合成系のみ③TIB 9/6・D-Global 9/30 と完全に競合し、9日間で公募要領精読〜申請書作成の品質が確保できない。**ただし「法人要件で不可」ではない（前回記載の訂正）。**
- **本命：2026年度公募（予告済・通年年4回程度）。** TRL4 実測値（9月末）と J-KISS 一段目の進展を持って申請するのが、採択確度・助成規模の両面で合理的。
- **DTSU 本体か GX 事業か：** CO2 削減の定量根拠が未実測の現状では **DTSU 本体（資源循環・資源安全保障の文脈）が自然**。エネルギー原単位の実測後に GX 事業への切替可否を再判定〔判断：加藤〕。

## 制度2：経産省 資源自律経済確立産官学連携加速化事業（執行団体：低炭素投資促進機構 GIO）

**公募期間：2026/8/6 〜 9/7（月）15時（jGrants 必着）【FACT】。**

### 確認できた要件【FACT・経産省公募ページ／検索結果】

| 項目 | 内容 |
| :-- | :-- |
| 補助率 | **中小企業等 1/2以内・大企業等 1/3以内**。実施主体に**地方公共団体を含む場合は中小 2/3以内・大企業 1/2以内** |
| 対象事業 | ①重要鉱物・金属資源・プラスチック等を対象とする**再生材の供給拡大・需要創出**の実証・設備投資 ②資源循環情報の可視化・共有 ③CEコマースのビジネスモデル確立 |
| 枠組み | サーキュラーパートナーズ（CPs）の枠組みを活用（入会要否〔要確認〕） |
| **補助対象期間** | **交付決定日〜令和9年（2027年）2月28日**──実質**約5か月の単年度事業** |

| 上限額 | 〔要確認：検索では特定できず。公募要領 PDF（GIO サイト）で確認〕 |
| 対象者の法人要件 | 「民間企業等」。設立準備中の扱いは**記載を確認できず**〔要確認。ただし補助金交付先として登記法人が前提の可能性が高い〕 |

### 当社への当てはめ（3重の壁）

1. **期間の壁（最大）：** 交付決定〜2027/2/28 の約5か月で実証・設備投資・実績報告まで完了が必要。当社の卓上検証機→実プラント側流の日程（2026Q4〜2027H1）と整合しない。
2. **概念適合の壁：** 対象①は「**再生材**の供給拡大・需要創出」のフレーム。当社は**未利用資源（排かん水中ヨウ素）の一次回収**であり、「再生材」概念への該当性が文言上不確実。ヨウ素が「重要鉱物・金属資源・プラスチック**等**」の「等」に読めるかも〔要確認〕。※該当性を主張する場合も「特定重要物資」等の政策指定は**使わない**（§5.3）。
3. **法人・CO2 の壁：** 設立準備中の扱いが不明。CO2 削減量の算定根拠はエネルギー原単位未実測の現状では弱い。

### 判定

- **今回（9/7 締切）：見送りを推奨。** 期間・概念適合・法人・CO2 算定の4点が揃って不利で、9日間で解消できない。
- **将来：** 本事業は年度公募が継続する系統（令和6年度：自律型資源循環システム強靱化促進事業→令和8年度：本事業）。**令和9年度公募を、千葉県を実施主体に含む座組（補助率 中小2/3）で狙う選択肢**を記録しておく。実測データ（TRL4・エネルギー原単位）が揃えば CO2 算定要件にも応えられる。県連携の相談は 9/8 CIC 定例・渡邉様ルートで温度感を測れる〔判断：加藤〕。
