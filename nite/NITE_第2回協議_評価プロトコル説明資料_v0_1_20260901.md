## 2. 評価指標の定義（回答書の思考実験への回答）

回答書 p.2 の「流入出比較と材内実測の乖離」は、当社の現行データにも該当します。現在公表している捕捉率は**上澄み側の紫外可視吸光度（351 nm）低下から算出**しており、脱着・回収工程を含みません。したがって「回収率」とは定義が異なります。第2回では次の3指標に分けて評価します。

| 指標 | 定義 | 測定点 | 分析法（案） |
| :-- | :-- | :-- | :-- |
| **q（捕捉量）** | 分離材 単位質量あたりのヨウ素捕捉量 ［mg-I／g-分離材］＝（C₀ − C₁）× V ÷ m | 処理前液 C₀・処理後上澄み C₁ | IC（I⁻）。UV 351 nm は相関クロスチェックに限定 |
| **R（脱着回収率）** | 温度サイクルで脱着液へ回収されたヨウ素量 ÷ 捕捉量 q×m ［%］ | 脱着液 C₂ | IC（I⁻）。必要に応じ ICP-MS |
| **分配係数比（I／Br 選択性）** | K_I ÷ K_Br、K＝（材内濃度）÷（水相平衡濃度）を同一条件で並行測定 | 上澄み中の I⁻ と Br⁻ | IC（I⁻・Br⁻ 同時分離定量） |
| **物質収支** | 処理前液 ＝ 上澄み残留 ＋ 脱着回収 ＋ 材内残留（差分） | 3点 | 差分 10% 超は再測定〔要確認：許容幅〕 |

## 3. 測定プロトコル（案）

### 3.1 試料調製
1. 温度応答性相分離後、沈殿を完全沈降させ上澄み水相を分取
2. シリンジフィルター（0.45 μm または 0.2 μm・親水性 PTFE／PVDF〔要確認：材質による I⁻/Br⁻ 吸着ロス〕）でろ過し、目視で清澄を確認
3. **ろ過・分離後に**還元剤（アスコルビン酸または NaHSO₃）を添加し、I₃⁻・遊離 I₂ を I⁻ へ変換（分離前に添加すると捕捉ヨウ素が脱着するため順序を固定）

### 3.2 分析体制（3層）

| 層 | 機関 | 手法 | 役割 |
| :-- | :-- | :-- | :-- |
| 第1層（主軸） | 県の公設試験研究機関 | IC（JIS K 0102-2 準拠）I⁻／Br⁻ 分離定量 | 公的試験成績書 |
| 第2層 | 同志社大学 学内共用設備 | ICP-MS（ISO 17294 参照）／学内 IC | ppb 域・形態別・クロスチェック |
| 第3層 | 民間受託分析機関 | 高塩分マトリクス対応 ICP-MS／IC | 実廃水（Cl⁻ 約2万 mg/L 共存）・日程バッファ |

### 3.3 試験マトリクス

| 系 | 目的 |
| :-- | :-- |
| 純水系 7 ppm | 基準系（q・R・再現性 n＝3〔要確認〕） |
| かん水モデル（人工海水 TDS 3.5 wt%・Cl⁻ 19,350 mg/L） | 共存イオン影響・分配係数比 |
| 実廃水 2種（A社提供） | 実液での q・R・選択性。テール濃度 約7 ppm 帯 |

### 3.4 温度条件
捕捉温度・放出温度（約40℃）のサイクルを固定し、各サイクルで q・R を記録〔要確認：捕捉温度・保持時間・分離材投与量〕。

## 5. 第2回協議でご相談したい事項

1. **指標定義**：§2 の q・R・分配係数比・物質収支の定義は、イオン交換（ISO 4907）・膜分離（ISO 20466）の指標体系と整合しているか。追加すべき指標はあるか。
2. **分析法**：JIS K 0102-2（IC）と ISO 17294（ICP-MS）の組合せ、還元前処理後の試料を IC で扱う際の留意点。公設試・ISO/IEC 17025 認定機関を用いる場合の要件。
3. **耐久性**：§4 の設計を JIS C 62506 に照らした場合の妥当性と、ラボ規模で現実的な負荷条件。
4. **標準化**：本評価法を将来 JIS／ISO へ展開する場合の手順（新市場創造型標準化制度の適用可能性を含む）。
5. **化審法・安全性**：既知モノマー由来の新規ポリマーについて、ポリマー特例を含む安全性確認の進め方（化審法連絡システムへの照会は別途実施〔要確認：実施状況〕）。
